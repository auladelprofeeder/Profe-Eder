📌 Relaciones entre conjuntos

Dados dos conjuntos A y B, entre ellos se pueden presentar las siguientes relaciones:

🔹 Inclusión (⊆)

Un conjunto A está incluido en B (es subconjunto de B) si y sólo si todos los elementos de A son elementos de B. Se simboliza A ⊆ B.
Es decir: A ⊆ B ⇔ ∀ x (x ∈ A ⇒ x ∈ B)

🔹 Igualdad (=)

Dos conjuntos A y B son iguales si todos los elementos de A están en B y todos los elementos de B están en A. Se simboliza A = B.

🔹 Intersecantes

Dos conjuntos A y B son intersecantes cuando tienen elementos comunes, pero ninguno está contenido en el otro.

🔹 Disyuntos

Dos conjuntos A y B son disyuntos cuando no tienen ningún elemento en común.

EJEMPLOS

Inclusión: A = {1, 2}, B = {1, 2, 3} → A ⊆ B.
Igualdad: C = {a, b, c}, D = {c, a, b} → C = D.
Intersecantes: E = {1, 2, 3}, F = {3, 4, 5} → comparten el 3.
Disyuntos: G = {rojo, azul}, H = {verde, amarillo} → ningún elemento en común.

🧩 Operaciones entre conjuntos

Las operaciones básicas son: unión, intersección, complemento, diferencia y diferencia simétrica. Aquí estudiaremos la unión y la intersección.

🔗 Unión (A ∪ B)

La unión de A y B es el conjunto formado por los elementos que pertenecen a A, a B o a ambos.
Por comprensión: A ∪ B = { x | x ∈ A ∨ x ∈ B }.

Propiedades de la unión

  • Conmutativa: A ∪ B = B ∪ A
  • Asociativa: (A ∪ B) ∪ C = A ∪ (B ∪ C)
  • Elemento neutro: A ∪ ∅ = A
  • Absorción con el universal: A ∪ U = U
EJEMPLOS UNIÓN

1. A = {1, 2, 4, 5} , B = {1, 2, 3, 6} → A ∪ B = {1, 2, 3, 4, 5, 6}.

2. A = {AM, AZ, RO} , B = {NE, BL, AM, AZ, MO} → A ∪ B = {AM, AZ, RO, NE, BL, MO}.

Representación gráfica (Venn): [A] contiene AM, AZ, RO ; [B] contiene NE, BL, AM, AZ, MO. La unión reúne todos los elementos sin repetir.

✂️ Intersección (A ∩ B)

La intersección de A y B es el conjunto formado por los elementos comunes a ambos.
A ∩ B = { x | x ∈ A ∧ x ∈ B }.

Propiedades de la intersección

  • Conmutativa: A ∩ B = B ∩ A
  • Asociativa: (A ∩ B) ∩ C = A ∩ (B ∩ C)
  • Distributiva: A ∩ (B ∪ C) = (A ∩ B) ∪ (A ∩ C)
  • Elemento absorbente: A ∩ ∅ = ∅
  • Neutro respecto al universal: A ∩ U = A
EJEMPLOS INTERSECCIÓN

1. A = {1, 2, 4, 5} , B = {1, 2, 3, 6} → A ∩ B = {1, 2}.

2. A = {AM, AZ, RO} , B = {NE, BL, AM, AZ, MO} → A ∩ B = {AM, AZ}.

✏️ Ejercicios propuestos

📌 Unión de conjuntos

  • 1a A = {1, 2, 3, 5, 7, 11} , B = {2, 4, 6, 8, 10}. Hallar A ∪ B.
  • 1b F = {ma, pe, uv, sa, me} , C = {pi, uv, fr, ma, an}. Hallar F ∪ C.
  • 1c V = {a, e, i, o, u} , C = {a, b, c, d, e, f, g, h, i}. Hallar V ∪ C.

📌 Intersección de conjuntos

  • 2a Z = {1, 2, 3, 4, 5, 6} , P = {1, 3, 5, 7, 9, 11}. Hallar Z ∩ P.
  • 2b R = {paloma, águila, canario, garza, tucán} , S = {gallo, pato, águila, tucán, mosca, garza}. Hallar R ∩ S.
  • 2c W = {5, 10, 15, 20, 25, 30} , Q = {10, 20, 30, 40, 50}. Hallar W ∩ Q.

📌 Interpretación de diagrama (AM, AZ, RO)

Usando la gráfica (descripción textual de un diagrama de Venn con tres conjuntos), responde:

  • 3 ¿A cuántos estudiantes les gusta AM y AZ? ______
  • 3 ¿A cuántos les gusta RO y AM? ______
  • 3 ¿Solo RO? ______
  • 3 ¿Solo AM? ______
  • 3 ¿Cantidad que gusta AZ? ______
  • 3 ¿Cantidad que gusta RO? ______
  • 3 ¿Gustan AM, AZ y RO a la vez? ______
  • 3 ¿Ninguna de las tres? ______
💡 Recuerda: En la unión los elementos repetidos se escriben una sola vez. En la intersección solo se escriben los elementos comunes. Los diagramas de Venn son herramientas visuales que facilitan la comprensión de las relaciones entre conjuntos.
